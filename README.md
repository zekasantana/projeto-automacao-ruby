# Projeto de Automação Ruby

Projeto prático para aprendizado de automação de testes Web utilizando Ruby, Capybara, Selenium WebDriver e RSpec.

## Tecnologias

- Ruby 4.0
- Capybara
- Selenium WebDriver
- RSpec
- Bundler
- Google Chrome

## Aplicação testada

[Demo Web Shop](https://demowebshop.tricentis.com/)

## Cenário implementado

- Acesso à página inicial;
- validação da mensagem de boas-vindas;
- abertura e encerramento automático do navegador.
